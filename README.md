Student Management System

A simple Student Management System built using Python, Flask, JavaScript, HTML, CSS, and SQLite.

Technologies Used

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript

Features

* Add new students
* View student records
* Edit student details
* Delete student records
* Search students by name
* Store student data using SQLite

Project Structure

python/

├── student_db.py
├── .gitignore
├── static/
│   ├── script.js
│   └── style.css
└── templates/
    └── index.html

How to Run

1. Install Python.
2. Install Flask:

pip install flask

3. Run the application:

py app.py

4. Open your browser:

http://127.0.0.1:5000
